# SignSpeak AI

Build a production-quality web application called "SignSpeak AI".

Purpose:

SignSpeak AI is an AI-powered accessibility platform that helps non-verbal users communicate using hand gestures. The application detects gestures through the webcam and converts them into text and speech in real time.
